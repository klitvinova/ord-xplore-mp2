## 🛠️ Summary of Changes

### 1. Backend API Routes
*   **[`api/dashboard.js`](file:///Users/karina/Local/IVDA/github%20version/app/api/dashboard.js)**
    *   Accepts `POST` filter requests and translates client state (date/geo source axes, selected language, countries, cities, years, custom features, topics, and date ranges) directly into transaction-isolated PostgreSQL SQL queries.
    *   Aggregates timeline counts, language distributions, unified city coords/countries, binary document characteristics, and active topics within a single database round-trip.
*   **[`api/upload.js`](file:///Users/karina/Local/IVDA/github%20version/app/api/upload.js)**
    *   Receives XML document string payloads, executes well-formedness and schema validations (ensuring root `<TEI>` or `<teiCorpus>` elements and namespace compliance), and runs JS XPath queries to extract metadata fields.
    *   Ingests the document and its nested children attributes, geolocations, time entities, languages, and topics transactionally into SQL.
    *   Includes a regex script frequency heuristic to auto-detect French, German, Latin, or English content when TEI language attributes are missing.

### 2. Security and Middleware
*   **[`middleware.js`](file:///Users/karina/Local/IVDA/github%20version/app/middleware.js)**
    *   Updated the Vercel edge middleware to block access only on `/upload.html`, `/upload`, and `/api/upload` routes.
    *   Prompts users for Basic Authentication credentials using Vercel environment variables, keeping the main `/index.html` dashboard fully public.

### 3. Frontend Integration
*   **[`index.html`](file:///Users/karina/Local/IVDA/github%20version/app/index.html)**
    *   Removed `Promise.all` static loaders loading the massive static files (`dashboard_data_optimized.json`, etc.).
    *   Replaced the client-side aggregation loop inside `updateDashboard()` with a dynamic POST fetch to `/api/dashboard`, rendering D3 timeline charts, Leaflet map markers, and topic hierarchies dynamically.
*   **[`upload.html`](file:///Users/karina/Local/IVDA/github%20version/app/upload.html)**
    *   Designed a premium dark-mode drag-and-drop ingestion page with dropzones, dynamic digital edition dropdown (with custom addition support), and realtime logs reporting extraction/validation results.

### 4. Schema Refinement & Local server
*   **[`server.js`](file:///Users/karina/Local/IVDA/github%20version/app/server.js)**
    *   Created a lightweight self-contained Node.js web server to test APIs and serve static files locally at `http://localhost:3000`.
*   **Database PK Alteration**
    *   Upgraded all primary key columns in `ord_xplore` to use `GENERATED BY DEFAULT AS IDENTITY` (instead of fixed integer requirements) and set safe high starting sequence offsets to support automated pipeline inserts without key conflicts.

## 🚀 How to Run Locally

1. Open your terminal in the `github version/app` directory.
2. Ensure you have Node.js installed.
3. Start the dev server:
   ```bash
   node server.js
   ```
4. Access the public dashboard at `http://localhost:3000/` and the protected upload pipeline at `http://localhost:3000/upload.html`.
