# Digital Editions Backend API - Setup & Usage Guide

## Prerequisites

Ensure you have Python 3.8+ installed with the following dependencies:
- fastapi
- uvicorn
- openai
- pydantic
- python-levenshtein
- requests

Install missing packages using: `pip install <package-name>`

## Starting the Backend Server

1. Open a terminal window
2. Navigate to the backend directory:
   ```
   cd ord-xplore-mp/misc_fall26/backend
   ```
3. Start the server:
   ```
   python main.py
   ```
4. Verify the server is running by visiting: http://127.0.0.1:8000/docs
   - If the interactive API documentation loads, the server is operational
   - If not accessible, check the terminal for error messages

## API Endpoints

Base URL: `http://127.0.0.1:8000/api/`

### POST /interpret
**Purpose:** Convert natural language queries into structured facet filters using OpenAI GPT.

**Request Format:**
```json
{
  "query": "your natural language search query here"
}
```

**Response:** Structured facet data compatible with the lookup endpoint

**Example Usage:** See `test_api.py` for implementation examples

### POST /lookup ⚠️ **Work in Progress**
**Purpose:** Transform facet filters into relevant document editions (IDEALISTIC - NOT CURRENTLY USED)

**Status:** This endpoint exists for future development but is not integrated into the current application workflow. The frontend dashboard uses the `/interpret` endpoint only.

**Request Format:** Accepts the exact output from `/interpret` endpoint

**Note:** While functional, this endpoint is not connected to the production search pipeline and should be considered experimental.

## API Documentation

Interactive documentation with request/response schemas available at:
http://127.0.0.1:8000/docs

## Testing

Use any HTTP client to test the endpoints:
- Postman
- curl
- Python requests library
- Browser-based REST clients

Example implementations available in `test_api.py`

## Stopping the Server

Press `Ctrl+C` in the terminal where the server is running for graceful shutdown.
