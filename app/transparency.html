Data Transparency & Methodology

This platform provides insights into digital editions by combining explicit metadata found in the source TEI/XML files with inferred characteristics derived from text analysis. This page explains how we process data to help you interpret the results with confidence.

Original / Explicit Data

Data directly extracted from standardized TEI tags (e.g., <lang>, <date>). We trust this data as authoritative.

Inferred Data

Data derived when explicit tags are missing. We use keyword analysis, structural pattern matching, and statistical methods (like language detection) to fill gaps.

1 TEI Tag Mapping & XPath Expressions

Each facet is extracted using specific XPath expressions that target TEI XML elements. Below is a comprehensive mapping of which tags contribute to each facet. Multiple paths are checked in priority order.

Temporal Perspectives (Creation, Publication, Content)
1. Creation Date (Historical Origin):

When the document was originally written or composed. Most valuable for historical analysis.

  • <teiHeader>//<origDate>
  • <profileDesc>/<creation>//<date>
  • <msDesc>/<origin>//<date>
  • <correspDesc>/<correspAction[@type='sent']>//<date>
2. Publication Date (Edition Date):

When the specific digital or printed edition was released.

  • <fileDesc>/<publicationStmt>//<date>
  • <teiHeader>//<docDate> (Fallback)
3. Content Date (Narrative Context):

Dates mentioned within the text itself (people, events, narratives).

  • <body>//<date>
  • <text>//<date>
  • <dateline>//<date>
Attributes Checked: @when, @when-iso, @from/@to, @notBefore/@notAfter
Language
Explicit Tags:
  • <textLang @ident>
  • <text @xml:lang>
  • Any element with @xml:lang attribute
Inference Method:

If no explicit language tag exists, we extract 3 text samples (300 chars each) from start, middle, and end of <body> and use statistical n-gram analysis (langdetect library) with 70% probability threshold.

Geographic Perspectives (Creation, Publication, Content)
1. Creation Place:

Location where the document was originally written.

  • <correspAction[@type='sent']>/<placeName>
  • <origPlace> in <msDesc>
2. Publication Place:

Location of the publisher or print shop.

  • <publicationStmt>//<pubPlace>
  • <docImprint>/<pubPlace>
3. Content Place (Contextual):

Any locations mentioned in the narrative body.

  • <body>//<placeName>
  • <body>//<settlement>, <region>, <geogName>
Enrichment & Geocoding:

We use a multi-pass pipeline to resolve these names to coordinates:
• Primary: Explicit @key attributes (GeoNames IDs).
• Refined: Fuzzy-matching against GeoNames Cities15000.
• Fuzzy: Normalization of historical spellings and suffix stripping.

2 Inference Methodology

Facet Methodology
Title Taken from <titleStmt> or <title>. Fallback to filename if missing.
Date
Explicit: Extracted from @when, @from/@to attributes on <origDate> or <docDate>.
Inferred: If explicit attributes are missing, we parse date strings (e.g., "circa 1850", "19th century") to estimate a year.
Language
Explicit: xml:lang attributes on text elements.
Inferred: Statistical n-gram analysis (langdetect) on 3 samples of body text (start, middle, end) if no tag is present.
Geography We extract places from <placeName>, <country>, etc. We enrich this by looking up unknown cities in the GeoNames database to infer their Country and Continent.

3 Content Characteristics (Detailed)

These boolean flags (True/False) describe the content. "Explicit" means a specific TEI tag exists. "Inferred" means we scanned the text for specific keywords or structural patterns.
Characteristic Detection Logic
Contains Verse Explicit: <lg> (line groups) or type="poem".
Inferred: Keywords like "poem", "verse", "lyric".
Is Letter Explicit: <correspDesc> or structural <opener>/<closer> tags.
Inferred: Keywords like "letter", "dear", "sincerely".
Is Manuscript Explicit Only: Presence of <msDesc> in the header.
Contains Direct Speech Explicit Only: Tags like <sp>, <u>, <q>.
Contains Theatre/Drama Explicit: type="drama".
Inferred: Structure with >10 speech tags (<sp>) plus stage directions (<stage>).
Is Medieval Manuscript Inferred: Manuscript dated 500–1500 CE.
East Asian / Japanese Scripts Explicit: xml:lang="ja" etc.
Inferred: Detection of Unicode character ranges (Hiragana, Katakana, CJK Ideographs).

4 Topics

Topics are generated using the FASTTopic model, a neural topic modeling approach that leverages pre-trained embeddings to discover coherent themes across disparate editions.

  • Topics are fully inferred; they are not explicit tags in the source files.
  • The names you see (e.g., "government, council, law") are the top most frequent words in that topic.
  • You can rename these topics in the dashboard to make them more human-readable.
